A one-line program that writes the self-checkout's verdict on your basket to entry.txt: twelve yoghurts, no spoon, and a shop that reads like a cry for help in dairy form. One 114-character line, deterministic, stdlib-only Python.

The entry line:

> Twelve yoghurts and no spoon? Bold. I've seen your basket — this is not a meal, it's a cry for help in dairy form.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/self-checkout-out python3 main.py
```
